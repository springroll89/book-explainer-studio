# 通用口播规范

适用：所有书籍精讲稿。事实来源与深度口径见 [忠实度规范](fidelity.md)，流程见 [WORKFLOW](../docs/WORKFLOW.md)。

剧情类同时遵守 [剧情文字总纲](narrative_charter.md)：随小说的揭示和松紧陪读者探索，解释从具体冲突与处境中长出来；每节无需附加道理或人物定论。

## 让听众只听声音也能懂

- 每句先讲一个清楚的动作或判断。长定语、插入语和多层转折拆开；句长阈值是定位信号，不能把自然短句补长凑指标。
- 人名、概念首次出现时带身份。跨段再出现时，必要时重复身份，别连续用“他”“它”“这个”让听众猜。
- 数字先说意义，再给必要的数值。公式、括号、缩写和引文的关系必须能用声音说清。
- 画面能补充口播，但关键论证不能依赖“看这张图”“看右边”。
- 保留长短句变化和自然停顿。不要每句都设问、每段都反转、每节都升华。

## 先有内容，再有钩子

开头用本集真实能回答的问题、反差或现场细节。后文要给出兑现，不把普通过渡句贴上钩子标记应付检查。钩子判定以独立 listener 的句子 ID 与触发原句对齐；估算时间只辅助制作。

## 改前 / 改后

以下是自写的说明例句，不是原书事实或用户认可样本。

| 问题 | 改前 | 改后 |
|---|---|---|
| 空泛开场 | 今天我们深入探讨一本发人深省的著作。 | 一个人明明已经拿到钥匙，为什么还站在门外？ |
| 长定语 | 他对于这种在长期压力下逐渐形成的行为模式的反思十分深刻。 | 他发现自己总在同一种时候逃开：事情快有结果了。他想知道，自己到底在怕什么。 |
| 画面依赖 | 看右边这张图，就知道差异很大。 | 第二组每十个人里，有六个人完成；第一组只有两个人。 |
| 空洞升华 | 这告诉我们，要勇敢地追求内心的答案。 | 到这里，他仍然没有开门。刚才那句“我已经想好了”，听起来就没那么确定了。 |

改写只能使用已核实的内容，示例中的具体数字和情节不可直接移植进稿件。

## 去 AI 腔的判断

删掉没有信息增量的导语、总结和重复评价。优先补动作、依据、因果链。自然对照句和连接词可以用，问题在用途和密度；[词表](banned.yaml)仅作提示，不按词表机械替换。默认语气见 [讲述者人设](voices/default.md)，采用项目已确认的风格时以项目约定为准。

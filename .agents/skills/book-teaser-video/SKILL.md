# 书籍先导片制作

本 skill 只处理用户提供的先导片剧本，不替用户改写全书剧情或自行选故事。独立于原有书籍技能运行；不要修改 visual-development 或其他既有 skill。

## 前置条件与开工资料

本书拆书、人物定妆和全季口播文案已完成；项目中能够找到文案、人物参考图和已选定的正片美术风格。先运行 `./run.sh next <项目路径>`，再读 `project.yaml`、派生的 `state.json`、分析/文案状态、画风确认记录、人物定妆索引及版本，核对书名和版本。候选仍标为 preview 时，沿用并保留其状态，不擅自称作定稿。

运行 ./run.sh guard <project> media-generate [--ep N]，只读取闸门结果；不得替用户运行 approve 或写审批记录。调用付费模型前估算费用，并遵守项目的用户授权规则。本流程独立于原有视觉开发，不套用其 8–15 秒静态图节奏规则。

## 剧本分析与先导片方案

保留用户剧本中的人物、事件、台词、悬念顺序和剧透边界，不添加原稿没有的剧情。按蒙太奇节奏拆成短小、独立、可剪辑的镜头；镜头间允许场景、人物、景别和气氛跳切，不强求连续动作或一镜到底。先确定每个镜头的成片时间线，再把相邻镜头组合成几个连续生成批次，兼顾参考图控制、返修范围和按秒计费。

批次须满足当前模型/API 的最小时长与时长步进。不要把每个 1–3 秒镜头都单独扩成 4 秒生成任务。尽量让批次生成时长等于所含镜头成片时长之和；若接口只接受整数秒，则按连续镜头重新分组，让每批向上取整的损耗最小，并列出预计计费秒数。把可能需要一起返修、画风和声场相近的相邻镜头放在同一批；批次不要超过接口上限。只有单镜头不适合合并、必须单独控图/声音，或用户选择单镜生成时，才单独请求，并事先说明最小时长造成的额外秒数。

对合并批次使用支持的多模态参考图模式，按上传顺序为每张关键画面写明镜头号与用途，并在一条提示词中为各镜头分配连续、不重叠的建议时间范围和场景切点。时间码用于表达镜头顺序与预期节奏，不要求模型逐帧精确命中；允许小幅时长和切点浮动。成片检查以镜头内容、声画关系和整体节奏为准，必要时按动作或声音的自然落点微调剪辑。参考图用于对应镜头的身份、构图和风格约束；它不是 API 可精确锁定到任意时间点的首尾帧。需在成片检查中核对镜头顺序、参考图归属和人物一致性。仅当一个任务确实从指定单张画面开始或结束时，才使用 first_frame / last_frame；不要拿多个镜头各自的首帧去重复创建多个最小时长任务。

分镜采用“关键镜头/关键画面”表，而不是默认首尾帧表。每条记录包含成片时间段、所在生成批次及批次内时码、构图与景别、画面动作、人物 ID、运镜、场景/道具、参考图、台词、声音设计及情绪。相邻镜头通过剪辑组成蒙太奇。

## 生成前的制作 MD 与用户确认

先生成一份版本化的先导片制作 MD，放在项目既有制作目录的独立先导片子目录中；若没有合适目录，可新建 production/teaser/。文件包含：

- 用户剧本引用/版本，以及内容、剧透和画风核对结果。
- 蒙太奇镜头表与生成批次表：镜头成片时间码、所在批次/批次内时码、参考图编号映射、各批生成秒数及总计费秒数。
- 每镜完整 Seedance 视听提示词、模型与请求参数草案，包括音频开关。
- 台词清单：准确原句、说话人、语言/口音、声音属性、情绪、语速、空间位置与混响意图。
- 拟音与环境声清单：发生时点、声源、前后景层次、强弱及与画面动作的同步点。
- 修改记录、待确认项、费用估算与执行边界。

MD 中的对话和声音设计是供 Seedance 直接生成的提示内容，不是后期配音清单。将完整 MD 交用户核对；用户明确确认制作方案前，不调用 Seedance 视频/声音生成。用户修改后更新版本并再次核对。

## Seedance 2.5 视听生成

按 references/seedance-implementation.md 和当前方舟官方文档操作。一个生成请求可按时间码包含数个连续蒙太奇镜头；视频、人物对白、旁白、环境声、拟音和可选音乐由同一 Seedance 请求生成，音频开关设为 generate_audio=true。不要将每个短镜头分别扩成模型最短时长，也不要默认转成静音生成或后期配音。

合并请求的提示词须逐段说明镜头边界和对应参考图，明确硬切/时间码，避免镜头之间互相串场。每段的声音仍按本镜头单独写准确台词、说话人、声线、情绪、时点、空间和拟音；批次之间的声线描述保持一致。角色音频只有在用户确认且官方接口支持 audio reference 时才作为参考，不能把现有 TTS 音色 ID 当成 Seedance 参数。

提示词将画面和声音放在同一条连续时间线中，明确指定：

- 人物说的准确原句、说话人和语言；原剧本未给的内容不能补写。
- 声线属性：性别、年龄感、音高/音域、音色质地、口音、语速、吐字和音量。
- 表演意图：具体情绪及强度、呼吸、停顿、犹疑或压迫感；避免只堆情绪形容词。
- 声音视角：入画/画外、近讲/远处、房间或电话带宽、空间反射和尾音；仅在镜头需要时描述口型同步。
- 拟音/环境声的声源、起止时点、节奏、质感、远近与混音优先级，以及需要与画面动作精确同步的事件。
- 是否使用音乐。默认不加背景音乐，只生成剧本需要的对白、拟音和环境声；用户明确需要时才加音乐。
- 不生成未写入剧本的对白、闲聊、临时旁白、哼唱或歌词，不改台词，不重复台词，不让环境人声盖过指定对白。不要字幕、可读文字、水印或 logo。

对白需要自然语速，不能为了硬塞时间码而加速到听不清。先将镜头按剧情顺序成组，再用清楚的镜头边界维持蒙太奇节奏。镜头时间码是节奏目标，可以小幅浮动；评价与剪辑优先看镜头顺序、内容完整、声画动作关系和自然节奏，不因轻微秒数偏差判为失败。提交前复核当前模型最小时长、时长步进和单任务上限；按照最终分组统计生成秒数和费用，避免未使用的生成时长。完整请求须记录模型 ID、duration、ratio、resolution、generate_audio、素材映射、批次提示词、任务 ID、状态、错误和输出路径。API key 仅从环境/安全配置读取，不写入提示词、日志或仓库。

## 试听、剪辑与返修

按批次观看和试听 Seedance 的一体化片段：核对每个切点、参考图归属、人物身份、台词原文、角色、语言、情绪、声线、节奏、对白可懂度、拟音时点、环境声空间、意外台词/人声及音画同步。确认每个批次里各镜头的实际起止时间，必要时按时间线裁切边界。

出现问题时先判断是否能通过支持的时间段编辑修复；不能时只重生成包含问题镜头的最小批次，重新核算该请求的最小时长和费用，不重做其他已合格批次。不要因单个镜头的错误自动重做整支片，也不要未经用户同意改成后期配音。按用户反馈进行通常一至两轮针对性返修。

将批次按总时间线拼接，尽量直接使用批次原生音轨，仅做必要的切点、音量平衡、交叉淡化或片尾收束。保留工程、批次源片段和各版成片。

## 封面与最终交付

完成先导片视听粗剪后，再依据剧本整体内容和已选画风，用内置 imagegen 分别生成两张独立构图：手机竖屏 9:16 和横屏 16:9。用户可以额外提供本书出版物封面作为可选视觉参考；先提炼可迁移的高层元素，如色彩关系、意象、材质、氛围或构图节奏，再与本项目已选画风、人物定妆照和先导片内容结合，重新创作。出版封面只是参考，不得照抄或临摹，不复用其独特版式、字体字形、插画细节或整体识别性组合，也不能通过局部替换文字/人物仿制原封面。

构图先传达故事场景、冲突或主题意象，不默认用人物大特写填满封面。优先考虑有叙事意味的环境、建筑、风景和关键物件；人物可缩小为场景中的角色或剪影，也可在人物不是主题重点时完全不出现。多人同框时变化人物朝向、动作、视线和景别，避免无叙事理由的姿势重复或所有人同时直视镜头。具体意象须由本书稿件/原文或用户提供的素材支持。

按本书类型、画风和用户反馈校准情绪强度。犯罪/悬疑作品可以营造疑问、压力和危险临近感，但不自动按恐怖片处理；密集重复、夸张畸变、强血红/洋红、滴落字效和极端阴影仅在原作类型与用户方向支持时使用。不要让单一噱头吞没全书情绪。若用户要求比较或视觉方向尚未收敛，先提出 2–3 个有明确差异的封面概念并说明象征重点，再生成对应尺寸。

书名作为图像的一部分，采用电影海报式手绘/书写/变形艺术字，使字形融入材质、笔触和场景氛围。不能用本机印刷字体后期叠字，不能只把一张封面裁成两个比例。生成时把书名作为唯一准确文字要求，预留干净标题区，不擅加副标题、作者、平台标识或剧情信息。逐字核对生成文字；错字、缺字或不可读时重生或编辑标题区域，不能用字体贴字补救。分别检查手机缩略图和横屏预览中的书名可读性、构图、安全边距、人物定妆一致性和剧透边界。

本书 visual-development 海报流程采用无字背景加本地字体排版，适用于常规系列海报；本先导片封面必须执行本节艺术字要求，不能直接复用字体叠字模式。

最终交付版本化制作 MD、素材映射与 Seedance 任务记录、合格的原生视听片段、约 20 秒单条先导视频，以及竖屏/横屏两张封面。报告检查结果和未完成项；候选画风/人物仍为 preview 时保留其状态。先导片默认不交付单独 TTS 台词音频。

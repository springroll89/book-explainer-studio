# calibrate-style

读取 [风格校准与反馈](../../../docs/WORKFLOW.md#风格校准与反馈)、项目配置及用户指定参考；只在需要时读 [口播规范](../../../style/spoken_rules.md)。

剧情类以 [剧情文字总纲](../../../style/narrative_charter.md) 和 [共享写法](../../../style/story_craft.md) 为基础。用户明确的跨书取向直接生效；缺少认可样稿表示声音与节奏尚待校准，不代表文案已经确认。

1. 分开记录可量化画像、阅读判断、用户明确偏好；参考稿缺失时标 `uncalibrated`，可先做默认预览。
2. 将发现写入 `style/benchmarks/`，列具体改前 / 改后及拟调整的规则、阈值和适用范围。
3. 已被用户明确要求的调整直接完成并验证；自行推导的扩大范围偏好保留候选。参考内容不等于可复制的认可样本。

用一段当前稿件检验建议是否提高可听性；不得以评论比例代替深度。

涉及画面时，先把“画风候选、固定人物锚点、原文事实 / 美术设定边界、用户确认状态”分开记录，再生成少量预览。角色一旦进入人物表，后续场景必须引用稳定 ID 和参考图；造型变化应记录为状态版本，不能临场换脸。静态画面以剧情信息和辨识度为准，不为填数量生成图片。详细的分镜、人物参考图和视觉验收按 [视觉开发](../visual-development/SKILL.md) 执行。

风格随全季改稿一并核对，文案确认按根目录交互规则记录；不能把参考稿或写作方向认可当成定稿批准。

`drafting.mode: full_season_review` 下，先使用已明确的文字取向写完全部集数，用户统一修改后再总结风格。下一步依 `next` 处理文案、样片和成片确认，不新增首集定调关卡。

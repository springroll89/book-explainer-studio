# update-ledger

本技能保留旧名称供已有入口发现，实际只维护 [统一前情表与依赖](../../../docs/WORKFLOW.md#统一前情表与依赖)，不再建立新旧两套账本。

1. 用 `next` 检查目标 `final.md`、当前审校与有效文案确认；从正文提取实际揭示、线索、身份、开放问题和回顾，不照抄计划。
2. 用 `recap snapshot-final <项目> <集号>` 保存候选；正文不同于已复核稿时显式提供 `--actual` 并重新语义复核，随后运行 `recap check`。保留原文批次、文件指纹和前序依赖。
3. 上游变化时列出所有受影响后集。逐集复核并更新它们自己的依赖记录；上游重新盖章不能自动解除下游待复核。

缺真实确认时，交付可审账本候选与待办，预览仍可完成；不能填写虚构的 approved-by 让正式流程通过。

旧书尚无前情表时，先运行 `recap migrate <项目>` 预览，核对后按授权显式 `--write`，逐集复核；不删除旧文件。助手小改可免重新确认，但不能绕过前情和媒体版本检查。

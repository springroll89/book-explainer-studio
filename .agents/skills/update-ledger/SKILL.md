# update-ledger

读取 [系列账本与依赖](../../../docs/WORKFLOW.md#系列账本与依赖)。

1. 检查目标 `final.md`、当前审校与真实 G4 确认；从正文提取已揭示事实、线索、身份、收获、开放问题和回顾，不照抄计划。
2. 保留定稿指纹、原文批次与前序依赖；按 `ledger --help` 写入并盖章，再运行 `ledger check`。
3. 上游变化时列出所有受影响后集。逐集复核并更新它们自己的依赖记录；上游重新盖章不能自动解除下游待复核。

缺真实确认时，交付可审账本候选与待办，预览仍可完成；不能填写虚构的 approved-by 让正式流程通过。

正式入账只认当前 `final.md` 哈希一致的 G4 用户批准记录；旧版 `--approved-by` 仅作兼容，不产生批准效力。

# 当前设计取舍

本文记录工作室当前实现采用的边界与取舍。阶段顺序和当前项目状态以 [`flow.py`](../bookflow/flow.py) 与 `next` 为准；操作步骤见 [工作流](WORKFLOW.md)，声音清单字段见 [媒体清单参考](../.agents/skills/produce-audio/references/media-manifest.md)。早期完整方案保存在 [`archive/DESIGN_REFERENCE_v1.1.md`](archive/DESIGN_REFERENCE_v1.1.md)。

## 架构

| 部分 | 责任 | 主要入口 |
|---|---|---|
| 会话与技能 | 阅读、写作、审校、提出选择；不伪造用户确认 | `.agents/skills/`、`roles/` |
| 状态与检查 | 按项目文件推导阶段、阻塞、证据和依赖 | `bookflow/`、`./run.sh next` |
| 项目资料 | 保存原文批次、版本稿、确认及媒体清单；不进入共享仓库 | 本机 `projects/<slug>/` |
| 媒体制作 | 依据配置和哈希清单执行可重跑的本地阶段；付费调用须显式启用 | `bookflow/produce.py`、适配器 |

## 关键取舍

- **程序管确定性，人员做语义判断。** 哈希、格式、引用定位、阶段顺序和依赖由代码核验；机器通过不代表事实、叙事或听感已被人验收。
- **原文与项目隔离。** 原文按不可变 generation 导入；共享仓库只包含通用代码、规则和原创夹具。真实书目、用户风格和本机路径留在本机。
- **确认绑定实际交付物。** 重新运行检查不应使确认失效；实际内容变化时指出文件、集数和差异，不以目录整体哈希代替解释。
- **媒体可断点续跑。** 每阶段记录输入、输出和费用；输入未变时复用有效产物。未知的服务结果不自动重发，未验证的付费接口不宣称已完成。
- **预览与正式交付分离。** 隔离夹具证明流程和媒体容器可运行，不代替正式服务账单、人工审校、实际试听、云端归档或发布验收。

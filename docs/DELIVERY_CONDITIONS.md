# 正式交付条件

`export --deliver` 逐项检查：

1. `final.md` 存在且状态为 `final`；
2. lint 与引文检查通过；
3. 三方独立审校报告与稿件哈希一致；
4. 原文批次和前序定稿依赖有效；
5. 当前稿件的句子锚点没有 orphaned 或未确认 text_changed；
6. 第一集音画样片存在有效 AV1 批准（后续集按项目规则）；
7. 字幕源文件来自当前最终稿，已按实际音频时间轴对齐，且视频中字幕可见；
8. `sound check` 无 error，音效清单状态和素材哈希可追溯，粗混响度符合 O13；
9. `release/compliance.yaml` 字段完整并有有效 RELEASE 批准。

机器不能判断的试听、版权和平台合规事项由批准记录承担。

# 首版实现取舍

采用 v1.1 的编辑流程，参考脚本未直接复制为生产实现。

## 已实现

- 一组 `python -m bookflow` 命令，避免维护多个重复入口。
- 不可变原文版本：`source/imports/<generation>/`，`source/current.json` 是唯一当前指针。
- 四层深度与核心收获校验；原文和书外来源采用不同编号。
- 机器查漏候选与人工审计分开，脚本不宣称“已确认没有遗漏”。
- 句子级 listener 输入；审校直接读取独立角色报告，汇总不能掩盖原报告错误。
- 定稿与后续集数的依赖指纹，阻止旧审稿被重新使用。
- 预览与正式交付区分；预览不要求捏造人工终审。

## 使用边界

这是代理辅助的编辑工作流，Python 不自动调用模型，也不自行判断作者意图。质量报告的内容由代理和人填写，文件哈希证明对应版本，不能证明语义判断必然正确。

第一集展示使用原创测试文本。任何机器或代理评分都未替代用户的风格认可。尚未生成或测量实际配音。

PDF/MOBI 先转换，首版不内置付费转换、OCR或TTS。没有依赖编辑器的自动写入钩子，关键检查由命令显式执行。
